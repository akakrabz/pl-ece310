{{#choices}}{{text}}{{/choices}} {{/params.statements}} Every DTFT is $2\pi$-periodic, finite signal or not. $X_d(\omega) = X(z)\big|_{z=e^{j\omega}}$ only when the ROC contains $\lvert z\rvert = 1$. A real $x[n]$ $\iff$ a Hermitian DTFT, $X_d(-\omega) = X_d^*(\omega)$. Only $e^{j\omega_0 n}$ is an eigenfunction of every LTI system; a cosine is two of them. Appending zeros never changes the DTFT. A magnitude is never negative and a phase response is a principal angle. Try the statement on $x[n] = \delta[n-1]$ ($X_d = e^{-j\omega}$), on $2^n u[n]$ (no DTFT), on the delay $y[n] = x[n-1]$ (it shifts a cosine), or on $h = \delta[n] + \delta[n-2]$ ($H_d = 2e^{-j\omega}\cos\omega$, which changes sign). For a formula $H_d(\omega)$ or $X_d(\omega)$, compare $X_d(-\omega)$ with $X_d^*(\omega)$ before using any shortcut for real signals.
