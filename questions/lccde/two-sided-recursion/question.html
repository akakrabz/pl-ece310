(c) The input $x[n] = {{params.x_tex}}$ is applied to the stable system. Find these output samples (exact values, as in (b)):

Partial fractions give $H(z) = \dfrac{A_1}{1-p_1z^{-1}} + \dfrac{A_2}{1-p_2z^{-1}}$. A stable system has the ROC that contains the unit circle; the pole inside it gives a right-sided (causal) term, the pole outside a left-sided (anti-causal) term. Each term satisfies $y_k[n] - p_k\,y_k[n-1] = A_k\,x[n]$. The causal term is solved for the newest sample and run forward from rest before the input starts. The anti-causal term is solved for the oldest sample, $y_a[n-1]$, and run backward from rest after the input has ended; divide the whole equation by $-p$. Then add the two outputs sample by sample.
