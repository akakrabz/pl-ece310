{{/params.is_lecture}} Count the bins first: only one DFT has $16$. Zero padding adds no data: the padded DFT evaluates the same DTFT at twice as many frequencies, so every second stem repeats the $16$-point DFT. Twice as many real samples make the peaks twice as tall and the main lobes half as wide. A Hamming window lowers the side lobes and widens the main lobes. A cosine $A\cos\left(\frac{2\pi k_0}{M}n\right)$ with a whole number of periods in $M$ samples gives $\lvert X[k_0]\rvert = \lvert X[M - k_0]\rvert = \frac{MA}{2}$ and zeros elsewhere ($M$ = number of real samples). Bin $k$ of a $32$-point DFT sits at $\omega_k = \frac{2\pi k}{32}$, and $\Omega = \frac{\omega}{T}$.
