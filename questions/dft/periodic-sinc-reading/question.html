{{#params.width_choices}}{{text}}{{/params.width_choices}} {{/params.predict}} Euler: $A\cos(\omega_0 n) = \frac A2 e^{j\omega_0 n} + \frac A2 e^{-j\omega_0 n}$. On $N$ samples each exponential gives a shifted copy of the DTFT of the length-$N$ rectangle, $C(\omega) = e^{-j\frac{\omega}{2}(N-1)}\,\dfrac{\sin(N\omega/2)}{\sin(\omega/2)}$, so $X_d(\omega) = \frac A2 C(\omega - \omega_0) + \frac A2 C(\omega + \omega_0)$. $C(0) = N$, and $C(\omega) = 0$ at every nonzero multiple of $\frac{2\pi}{N}$: the main lobe is centred on the frequency, its zeros sit $\frac{2\pi}{N}$ on either side (width $\frac{4\pi}{N}$), and the cosine's lobe is $\frac{A}{2}\cdot N$ tall. Only the number of samples changes the width.

$X_d(\omega) = \frac A2 C(\omega - \omega_0) + \frac A2 C(\omega + \omega_0)$: near $\omega_0$ the lobe $\frac A2 C(\omega - \omega_0)$ dominates, with height $\frac{A}{2}\cdot N$, zeros at $\omega_0 \pm \frac{2\pi}{N}$ and width $\frac{4\pi}{N}$ (Lecture 22, eqs. 8–10).

(a) The main lobe is centred midway between its zeros: $$\omega_0 = \frac{1}{2}\left({{params.lo_tex}} + {{params.hi_tex}}\right) = \frac12\cdot{{params.sum_tex}} = {{params.w0_tex}}.$$

(b) Null-to-null width: ${{params.hi_tex}} - {{params.lo_tex}} = {{params.width_tex}} = \frac{4\pi}{N}$, so $$N = \frac{4\pi}{ {{params.width_tex}} } = {{params.N}}.$$

(c) The peak height is $\frac{AN}{2}$ to the accuracy of the plot, so $\frac{A\cdot {{params.N}}}{2} = {{params.H}}$ and $$A = \frac{2\cdot {{params.H}}}{ {{params.N}} } = {{params.A}}.$$

Here $\omega_0 = {{params.w0_tex}} = \frac{ {{params.k}}\pi}{ {{params.N}} }$, so $\omega_0$ is a zero of the mirror lobe $C(\omega + \omega_0)$: $\lvert X_d(\omega_0)\rvert = {{params.H}}$ exactly, and the true maximum ($\approx {{params.peak_exact}}$) differs from it by ${{params.peak_pct}}$ %.

(a) $\omega_0 = {{params.w0_tex}}$, $N = {{params.N}}$, $A = {{params.A}}$: $$\lvert X_d(\omega_0)\rvert \approx \frac{A N}{2} = \frac{ {{params.A}}\cdot {{params.N}} }{2} = {{params.H}}.$$ (Not $AN$: each of the two exponentials carries $\frac A2$. Here $\omega_0 = {{params.w0_tex}} = \frac{ {{params.k}}\pi}{ {{params.N}} }$ is a zero of the mirror lobe, so the value is exact.)

(b) The zeros of $C(\omega - \omega_0)$ next to its peak are $\frac{2\pi}{N} = {{params.half_tex}}$ away: $$\omega_{\text{lo}} = {{params.w0_tex}} - {{params.half_tex}} = {{params.lo_tex}},\qquad \omega_{\text{hi}} = {{params.w0_tex}} + {{params.half_tex}} = {{params.hi_tex}}$$ (width $\frac{4\pi}{N} = {{params.width_tex}}$).

(c) The width $\frac{4\pi}{N}$ halves only when the number of samples doubles: keep $N' = {{params.N2}}$ samples (the lobe also becomes twice as tall, $\frac{A N'}{2}$). Zero padding does not change $X_d(\omega)$ at all, it only samples it more densely; a Hamming window makes the main lobe about twice as wide ($\frac{8\pi}{N}$); $4N$ samples give a quarter of the width, $\frac N2$ samples double it; the amplitude only scales the height.
