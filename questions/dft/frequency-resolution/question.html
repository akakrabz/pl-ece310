{{{params.fig2_html}}} {{#params.proc_choices}}{{text}}{{/params.proc_choices}} {{/params.fa23}} A length-$N$ cosine at $\omega_0$ has a main lobe of width $\frac{4\pi}{N}$ centred at $\omega_0$ (zeros at $\omega_0 \pm \frac{2\pi}{N}$), and its height grows with the number of samples, $\frac{AN}{2}$. The DFT evaluates the DTFT at $\omega_k = \frac{2\pi k}{N}$; a tone at $f$ Hz sits at $\omega = \frac{2\pi f}{f_s}$. Full-lobe: $\lvert\omega_2 - \omega_1\rvert \gt \frac{4\pi}{N}$; half-lobe: $\lvert\omega_2 - \omega_1\rvert \gt \frac{2\pi}{N}$, applied to the closest pair. A Hamming window doubles the main-lobe width ($\frac{8\pi}{N}$). Zero padding does not change the DTFT; it only evaluates it on a finer grid, so the old DFT values reappear at every other bin. {{#params.l23}}

Only the closest pair matters: if it is separated, every pair is. Adjacent spacings: ${{params.gaps_tex}}$ Hz, so the closest pair is ${{params.f1}}$ and ${{params.f2}}$ Hz, $\Delta f = {{params.df}}$ Hz, and $$\Delta\omega = \lvert\omega_2 - \omega_1\rvert = (\Omega_2 - \Omega_1)T = {{params.dw_tex}}\ \text{rad/sample}.$$

(a) $$N \gt \frac{4\pi}{\Delta\omega} = \frac{2 f_s}{\Delta f} = N_{\text{full}} = {{params.Nf}},\qquad N \gt \frac{2\pi}{\Delta\omega} = \frac{f_s}{\Delta f} = N_{\text{half}} = {{params.Nh}}.$$

(b) $$NT \gt N_{\text{full}}\,T = \frac{ {{params.Nf}} }{f_s} = \frac{2}{\Delta f} = {{params.Tf_tex}}\ \text{s}\ (\approx {{params.Tf_dec}}\ \text{s});$$ half-lobe needs only $\frac{1}{\Delta f} = {{params.Th_tex}}$ s.

(c) The Hamming main lobe is twice as wide, $\frac{8\pi}{N}$, so every bound doubles: $N \gt \frac{8\pi}{\Delta\omega} = \frac{4 f_s}{\Delta f} = N_{\text{Ham}} = {{params.Nham}}$ (the price of its much lower side lobes).

(d) $N_{\text{full}} = \frac{2 f_s}{\Delta f}$ is proportional to $f_s$: at $f_s' = {{params.fs2_tex}}$ it becomes ${{params.Nf2_tex}}$ ({{params.Nf2_word}}), because $\Delta\omega = \frac{2\pi\Delta f}{f_s}$ changes the other way. The time $N_{\text{full}}T = \frac{2}{\Delta f}$ does not depend on $f_s$: resolution is set by how long you record, not by how fast you sample.

Each tone gives a main lobe of width $\frac{4\pi}{L}$ (zeros $\frac{2\pi}{L}$ on either side of its peak), and a tone at $f$ Hz sits at $\omega = \frac{2\pi f}{f_s}$, so $\Delta\omega = \frac{2\pi\,\Delta f}{f_s}$.

(a) Full-lobe: $\frac{2\pi\,\Delta f}{f_s} \gt \frac{4\pi}{L} \iff \Delta f \gt \frac{2 f_s}{L} = \frac{2}{D}$, so $\Delta f_{\text{full}} = \frac{2\cdot {{params.fs}}}{ {{params.L}} } = {{params.dff_tex}}$ Hz. Half-lobe: $\Delta f \gt \frac{f_s}{L} = \frac{1}{D}$, so $\Delta f_{\text{half}} = {{params.dfh_tex}}$ Hz. Only the duration $D = \frac{L}{f_s}$ matters.

(b) $\Delta\omega_{\text{full}} = \frac{4\pi}{L} = \frac{4\pi}{ {{params.L}} } = {{params.dwf_tex}}$ (Lecture 23, eq. 9).

(c) The Hamming main lobe is twice as wide, $\frac{8\pi}{L}$: $\Delta f_{\text{Ham}} = \frac{4 f_s}{L} = \frac{4}{D} = {{params.dfham_tex}}$ Hz.

(d) Unchanged: zero padding adds only zeros, so the DTFT, and with it the main-lobe width $\frac{4\pi}{L}$, stays the same; the $N$-point DFT just evaluates that DTFT on a finer grid (bins ${{params.bin_tex}}$ Hz apart). A spacing that full-lobe separation does not guarantee with $L$ samples (two lobes that run together) is still one merged lobe after padding. Only a longer recording narrows the lobes.
