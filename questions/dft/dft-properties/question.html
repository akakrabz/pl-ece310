The $N$-point DFT of a length-$N$ signal $\{x[n]\}_{n=0}^{N-1}$ is $X[k] = \sum_{n=0}^{N-1} x[n]\,e^{-j\frac{2\pi}{N}kn}$, $k = 0, 1, \dots, N-1$; $\langle n\rangle_N$ denotes $n$ modulo $N$ (a number in $\{0, 1, \dots, N-1\}$).

Let $\{x[n]\}_{n=0}^{ {{params.Nm1}} } = {{params.x_tex}}$ be a length-${{params.N}}$ signal with ${{params.N}}$-point DFT $\{X[k]\}_{k=0}^{ {{params.Nm1}} } = {{params.X_names_tex}}$.

(a) The ${{params.N}}$-point DFT of another length-${{params.N}}$ signal $\{y[n]\}_{n=0}^{ {{params.Nm1}} }$ is $${{params.Y_def_tex}}.$$ {{#params.ask_vec}} Determine $y[n]$ for $n = 0, 1, \dots, {{params.Nm1}}$, as a row vector (entries separated by commas inside brackets; complex entries are typed like 2+3j or -j, with no spaces or * inside an entry: type -3j, not -3 j or j3; e.g. [1, -2+3j, 0]).

{{/params.ask_vec}} {{#params.ask_formula}} Then $y[n]$ can be written as $$y[n] = c\,e^{j\frac{2\pi}{ {{params.N}} }\ell n}\,x[\langle n - n_0\rangle_{ {{params.N}} }],\qquad n = 0, 1, \dots, {{params.Nm1}},$$ with $c \in \{1, -1\}$ and integers $0 \le \ell \le {{params.Nm1}}$, $0 \le n_0 \le {{params.Nm1}}$. Find $c$, $\ell$ and $n_0$.

{{/params.ask_formula}}

(b) Exactly one of the following lists is the ${{params.M}}$-point DFT $\{Z[k]\}_{k=0}^{ {{params.Mm1}} }$ of a real-valued signal $\{z[n]\}_{n=0}^{ {{params.Mm1}} }$. Which one?

{{#params.real_list_choices}}{{text}}{{/params.real_list_choices}} $x[\langle n - m\rangle_N] \leftrightarrow e^{-j\frac{2\pi}{N}km}X[k]$ (circular delay by $m$; a plus sign in the exponent is an advance), $e^{j\frac{2\pi}{N}\ell n}x[n] \leftrightarrow X[\langle k - \ell\rangle_N]$, $x[\langle -n\rangle_N] \leftrightarrow X[\langle -k\rangle_N]$, $x^*[\langle -n\rangle_N] \leftrightarrow X^*[k]$, and $\sum_{m} x[m]\,h[\langle n - m\rangle_N] \leftrightarrow X[k]H[k]$. Every index lives on a circle of $N$ points. Test your answer on one sample: $y[0]$ must come out right. $(-1)^k = e^{-j\frac{2\pi}{N}k\frac{N}{2}}$ is a circular shift by $\frac N2$, while $(-1)^n$ multiplying $x[n]$ shifts the DFT by $\frac N2$ bins. A real signal has a Hermitian DFT: $X[0]$ (and $X[N/2]$ for even $N$) real, and $X[k] = X^*[\langle -k\rangle_N] = X^*[N - k]$.
