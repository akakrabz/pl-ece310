The identities that do the work: $e^{j\frac{2\pi}{2N}(k+N)n} = e^{j\frac{2\pi}{2N}kn}(-1)^n$, $e^{j\frac{2\pi}{2N}(2k)n} = e^{j\frac{2\pi}{N}kn}$ (which is $N$-periodic in $n$), and $e^{-j\frac{2\pi}{N/2}k(n + N/2)} = e^{-j\frac{2\pi}{N/2}kn}$. For the properties: $x[\langle n - m\rangle_N] \leftrightarrow e^{-j\frac{2\pi}{N}km}X[k]$, $x[\langle -n\rangle_N] \leftrightarrow X[\langle -k\rangle_N]$, $e^{j\frac{2\pi}{N}\ell n}x[n] \leftrightarrow X[\langle k - \ell\rangle_N]$. Check $y[0]$: it is $\frac{1}{M}$ times the sum of all $M$ values in the new list, and $\sum_k X[k] = N x[0]$. {{#params.is_fa21}}For $Y$: $Y[0] = \sum_n y[n]$ can be computed directly from the eight values of $y[n]$.{{/params.is_fa21}} Compare the lengths too: the new DFT has {{#params.real_kind}}${{params.M}}${{/params.real_kind}}{{#params.is_fa21}}$8${{/params.is_fa21}} values, so $y[n]$ has that many samples. {{#params.is_dup}}

(a), (b) (FA2025 Midterm 2 #7.) $Y[k] = X[k]$ for $0 \le k \le N-1$ and $Y[k] = X[k - N]$ for $N \le k \le 2N - 1$. In the length-$2N$ inverse DFT, split the sum at $k = N$ and put $k = m + N$ in the second half: $$\begin{aligned} y[n] &= \frac{1}{2N}\sum_{k=0}^{N-1}X[k]e^{j\frac{2\pi k}{2N}n} + \frac{1}{2N}\sum_{m=0}^{N-1}X[m]e^{j\frac{2\pi (m+N)}{2N}n} \\ &= \frac{1 + (-1)^n}{2N}\sum_{k=0}^{N-1}X[k]e^{j\frac{\pi k}{N}n}, \end{aligned}$$ because $e^{j\frac{2\pi N}{2N}n} = e^{j\pi n} = (-1)^n$. For odd $n$ the factor $1 + (-1)^n$ is $0$; for $n = 2r$ it is $2$ and $e^{j\frac{\pi k}{N}2r} = e^{j\frac{2\pi k}{N}r}$, so $y[2r] = \frac1N\sum_k X[k]e^{j\frac{2\pi k}{N}r} = x[r]$. Hence $y[2n] = x[n]$, $y[2n+1] = 0$: repeating the DFT upsamples the signal by $2$. Here $$\{y[n]\}_{n=0}^{ {{params.Mm1}} } = {{params.work_tex}} = {{params.y_tex}}.$$

(a), (b) Only the even-indexed values are nonzero, $Y[2k] = X[k]$. The length-$2N$ inverse DFT keeps only those terms: $$y[n] = \frac{1}{2N}\sum_{k=0}^{N-1}X[k]\,e^{j\frac{2\pi (2k)}{2N}n} = \frac12\cdot\frac1N\sum_{k=0}^{N-1}X[k]\,e^{j\frac{2\pi k}{N}n} = \tfrac12\,x[\langle n\rangle_N],$$ since the length-$N$ inverse-DFT formula is $N$-periodic in $n$.
