(b) Whatever your answer to (a): if the system were LTI, pair 1 would determine its impulse response $h[n]$. Using that $h[n]$, find the output for the new input $$v[n] = {{params.v_tex}}.$$ Enter the index of the first nonzero output sample and the output samples from the first to the last nonzero one as a row vector (for example [25, 0, -30]).

Look for relations among the inputs. If one input is a pure shift of another, time-invariance forces the same shift between their outputs. If one input is a linear combination of others ($c\,x_2$, $x_2 + d\,x_1$), linearity forces the same combination of outputs. An LTI system must in addition satisfy $y = x * h$ with one $h$ for all pairs. A relation that the outputs violate disproves the corresponding property. A linear system may map linearly independent inputs to any outputs; a time-invariant system may map inputs that are not shifts of one another to any outputs. So a property is disproved only by a relation that involves it alone. For (b): if $\delta[n - m] \mapsto y_1[n]$ for an LTI system, then $\delta[n] \mapsto y_1[n + m]$, i.e. $h[n] = y_1[n + m]$.
