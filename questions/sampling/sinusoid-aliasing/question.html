{{#params.b_choices}}{{text}}{{/params.b_choices}} $x_a(nT)$ replaces $t$ by $n/f_s$: $\cos(2\pi f_0 t + \theta)$ becomes $\cos(\omega_0 n + \theta)$ with $\omega_0 = 2\pi f_0/f_s$. Adding $2\pi$ to $\omega_0$ changes no sample. A sine is $\sin\alpha = \cos(\alpha - \tfrac{\pi}{2})$. If $\omega_0$ reduced mod $2\pi$ lands in $(\pi, 2\pi)$, write it as $2\pi - \omega$: $\cos\big((2\pi - \omega)n + \phi\big) = \cos(-\omega n + \phi) = \cos(\omega n - \phi)$. The frequency folds back and the phase changes sign. For a sine (or a cosine with a phase) only $+\omega_0 + 2\pi k$ reproduces the samples; $\sin(-\omega n) = -\sin(\omega n)$.
