A rectangular path with one side inside (length $L$, along the axis) and one outside links $nLI$ amperes, where $n = N/\ell$ is the turn density, so $H = nI$ inside and $0$ outside. The flux through one turn is $\Psi = \mu_0 H\,\pi a^2$; all $N$ turns link it, so $\Lambda = N\Psi = LI$ defines $L = N\Psi/I = \mu_0 N^2\pi a^2/\ell$. Then $W = \tfrac12 LI^2$ (equivalently $\tfrac12\mu_0H^2$ times the interior volume) and $\tau = L/R$.

(a) $H = nI = \dfrac{N}{\ell}I = \dfrac{ {{params.N}} }{ {{params.L_m}} }\times{{params.I}} = {{params.H_str}}\ \mathrm{A/m}$.

(b) $\Psi = \mu_0 H\,\pi a^2 = {{params.B_str}}\ \mathrm{mT}\times{{params.A_str}}\ \mathrm{m^2} = {{params.Psi_str}}\ \mu\mathrm{Wb}$.

(c) $L = \dfrac{N\Psi}{I} = \dfrac{\mu_0N^2\pi a^2}{\ell} = {{params.L_str}}\ \mu\mathrm{H}$ — proportional to $N^2$: doubling the turns doubles both the field per ampere and the number of turns that link it.

(d) $W = \tfrac12LI^2 = {{params.W_str}}\ \mu\mathrm{J}$; the same number comes from the energy density $\tfrac12\mu_0H^2 = {{params.w_str}}\ \mathrm{J/m^3}$ times the interior volume $\pi a^2\ell = {{params.vol_str}}\ \mathrm{m^3}$.

(e) $L\,dI/dt = -RI$ gives $I(t) = I_0e^{-t/\tau}$ with $\tau = L/R = {{params.tau_str}}\ \mu\mathrm{s}$. The stored $W$ is dissipated in $R$.
