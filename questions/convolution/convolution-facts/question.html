{{#params.prop_choices}}{{text}}{{/params.prop_choices}} If $x$ occupies $n_s \le n \le n_e$ (length $N$) and $h$ occupies $m_s \le n \le m_e$ (length $M$), then $y = x * h$ starts at $n_s + m_s$, ends at $n_e + m_e$ and has length $N + M - 1$ (Lecture 4, eqs. 15–17). $\sum_n y[n] = \sum_n\sum_k x[k]\,h[n-k] = \big(\sum_k x[k]\big)\big(\sum_m h[m]\big)$. At the first index only the first samples of $x$ and $h$ overlap (one product), likewise at the last index. In general $y[n_0] = \sum_k x[k]\,h[n_0 - k]$: keep only the $k$ for which both factors lie inside their supports.

(a) $x$ occupies ${{params.a1}} \le n \le {{params.b1}}$ (length ${{params.lx}}$) and $h$ occupies ${{params.a2}} \le n \le {{params.b2}}$ (length ${{params.lh}}$), so $n_{\text{first}} = {{params.first_tex}} = {{correct_answers.nfirst}}$, $n_{\text{last}} = {{params.last_tex}} = {{correct_answers.nlast}}$ and the length is ${{params.len_tex}} = {{correct_answers.leny}}$ (check: ${{correct_answers.nlast}} - ({{correct_answers.nfirst}}) + 1 = {{correct_answers.leny}}$).
