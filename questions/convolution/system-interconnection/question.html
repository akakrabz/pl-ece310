The LTI system below is built from three FIR blocks with impulse responses $$ {{params.blocks_tex}} $$ (the arrows mark $n = 0$; all samples not shown are zero) and a delay block. A block labelled $z^{-k}$ delays its input by $k$ samples; a circle adds its inputs with the signs written next to them.

{{{params.fig_html}}}

(a) Find the overall impulse response $h[n]$ from $x[n]$ to $y[n]$: the index of its first nonzero sample, and its samples from the first to the last nonzero one as a row vector (for example [20, 0, -30, 40]).

(b) Find the overall transfer function $H(z)$. Type z^(-2) for $z^{-2}$; products of polynomials are fine, e.g. (5 - z^(-1))*(4 + 7*z^(-3)).

(c) {{#params.is_delta}}The input is $x[n] = \delta[{{params.m_tex}}]$. Find the output sample $y[{{params.n0}}]$.{{/params.is_delta}} {{#params.is_const}}The input is the constant $x[n] = {{params.c_tex}}$ for all $n$. The output is constant too; find its value.{{/params.is_const}}

Blocks in series multiply: $H_1(z)H_2(z) \leftrightarrow h_1[n] * h_2[n]$. Branches that meet at an adder add (with their signs): $H_1(z) \pm H_2(z) \leftrightarrow h_1[n] \pm h_2[n]$. A delay block is $z^{-k} \leftrightarrow \delta[n-k]$. Work from the innermost connection outwards (Lecture 10, Table 1). Write each block as a polynomial in $z^{-1}$, e.g. $\{\underset{\uparrow}{1}, -2\} \to 1 - 2z^{-1}$. Multiplying the polynomials is the convolution, adding them adds the impulse responses, and the coefficient of $z^{-n}$ in the result is $h[n]$. An input $\delta[n - m]$ gives $y[n] = h[n - m]$; a constant input $c$ gives the constant $c\,H(1)$, with $H(1) = \sum_n h[n]$.
