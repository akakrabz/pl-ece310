 {{/params.is_stable}} An LTI system is BIBO stable if and only if $\sum_n \lvert h[n]\rvert \lt \infty$ (Lecture 4). A bounded $h[n]$ is not enough, and neither is $h[n] \to 0$: the terms must be summable. Take absolute values before summing. For $0 \le r \lt 1$: $\sum_{n=k}^{\infty} r^{n} = \dfrac{r^{k}}{1-r}$ and $\sum_{n=0}^{\infty} n\,r^{n} = \dfrac{r}{(1-r)^{2}}$. For a left-sided part substitute $n = -m$; then $b^{n} = (1/b)^{m}$ decays only if $\lvert b\rvert \gt 1$. Watch where each sum starts and count $n = 0$ exactly once.
