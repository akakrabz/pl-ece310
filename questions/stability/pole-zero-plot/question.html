{{#params.kind_s_choices}}{{text}}{{/params.kind_s_choices}} Each zero $z_k$ gives a factor $(z - z_k)$ in the numerator and each pole $p_k$ a factor $(z - p_k)$ in the denominator; a zero at the origin is a factor $z$. The plot fixes $H(z)$ only up to a constant $K$: $H(z) = K\,\prod_k (z - z_k)\big/\prod_k (z - p_k)$. Use the given condition to find $K$. A conjugate pair $a \pm jb$ multiplies out to $z^2 - 2az + a^2 + b^2$. The possible ROCs are bounded by the circles through the poles (zeros play no role). Causal: outside the outermost pole. BIBO stable: the ROC contains the unit circle $\lvert z\rvert = 1$; an ROC that only touches it (a pole on the circle) does not count. Outside a circle = right-sided, inside = left-sided, a ring = two-sided (Lecture 11, Table 1).

(b) $H(z)$ has no more finite zeros than poles, so it is finite at $z = \infty$, and a causal system has the ROC outside its outermost pole, including $z = \infty$: ${{params.causal_roc_tex}}$.

(c) {{#params.causal_stable}}Every pole is inside the unit circle ($\lvert p\rvert_{\max} = {{params.rmax_tex}} \lt 1$), so the causal ROC ${{params.causal_roc_tex}}$ contains $\lvert z\rvert = 1$: yes, the causal system is BIBO stable.{{/params.causal_stable}} {{#params.causal_unstable}}{{#params.rmax_on}}The outermost pole lies on the unit circle, so the causal ROC ${{params.causal_roc_tex}}$ only touches $\lvert z\rvert = 1$ without containing it: no, the causal system is not BIBO stable.{{#params.marginal}} (It is marginally stable: its poles on the unit circle are simple, so $h[n]$ stays bounded, but a bounded input with a pole at the same place gives an unbounded output.){{/params.marginal}}{{#params.on_repeated}} The pole on the unit circle is repeated, so $h[n]$ itself grows like $n$ (e.g. $n\,a^n u[n]$ with $\lvert a\rvert = 1$): already $x[n] = \delta[n]$ gives an unbounded output. This is not marginal stability, which needs simple poles on the circle.{{/params.on_repeated}}{{/params.rmax_on}}{{^params.rmax_on}}The outermost pole has magnitude ${{params.rmax_tex}} \gt 1$, so the causal ROC ${{params.causal_roc_tex}}$ misses the unit circle: no, the causal system is not BIBO stable.{{/params.rmax_on}}{{/params.causal_unstable}}
