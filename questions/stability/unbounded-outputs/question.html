A causal LTI system has the transfer function $$H(z) = {{params.H_tex}}.$$ Each signal below is a bounded input. Select every input for which the output $y[n]$ is unbounded.

{{#params.x_choices}}{{text}}{{/params.x_choices}} $Y(z) = H(z)X(z)$. Cancel common factors first. Then $y[n]$ is unbounded exactly when $Y(z)$ has a pole outside the unit circle or a repeated pole on it. A simple pole on $\lvert z\rvert = 1$ only gives a bounded oscillation. $e^{j\omega_0 n}u[n]$ has one pole, at $e^{j\omega_0}$; $\cos(\omega_0 n)u[n]$ and $\sin(\omega_0 n)u[n]$ have two, at $e^{\pm j\omega_0}$; $a^n u[n]$ has a pole at $a$; $\delta[n-k]$ has none. Compare angles exactly: $\tfrac{2}{3}$ rad is not $\tfrac{2\pi}{3}$, and a conjugate $e^{-j\omega_0}$ is a different point from $e^{j\omega_0}$.

The poles of $H$ are {{{params.pole_desc_html}}}.{{{params.cancel_html}}} The system is causal, so its ROC is $\lvert z\rvert \gt 1$: it does not contain the unit circle, the system is marginally stable (not BIBO stable), and $h[n]$ is bounded but not absolutely summable. An input gives an unbounded output only if it resonates: one of its poles lands exactly on a surviving pole of $H$ on the unit circle, creating a double pole there.
