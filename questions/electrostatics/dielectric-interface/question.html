Tangential $\mathbf{E}$ is continuous ($E_{2x} = E_{1x}$); normal $\mathbf{D}$ is continuous when there is no free surface charge ($\epsilon_1 E_{1z} = \epsilon_2 E_{2z}$). Not the other way round. $\mathbf{P} = \mathbf{D} - \epsilon_0\mathbf{E} = (\epsilon_r - 1)\,\epsilon_0\mathbf{E}$ in each medium. Bound surface charge: $\rho_{sb} = -\hat{n}\cdot(\mathbf{P}_1 - \mathbf{P}_2) = P_{2z} - P_{1z}$.

(a) $E_{2x} = E_{1x} = {{params.E1x}}$; $E_{2z} = \dfrac{\epsilon_1}{\epsilon_2}E_{1z} = \dfrac{ {{params.er1}} }{ {{params.er2}} }\times({{params.E1z}}) = {{params.E2z}}\ \mathrm{V/m}$.

(b) $D_{1z} = {{params.er1}}\,\epsilon_0 E_{1z} = {{params.D1z}}\,\epsilon_0$ (and $D_{2z}$ is the same — normal $\mathbf{D}$ is continuous); $D_{2x} = {{params.er2}}\,\epsilon_0 E_{2x} = {{params.D2x}}\,\epsilon_0$ (tangential $\mathbf{D}$ jumps).

(c) $P_{1x} = ({{params.er1}}-1)\,\epsilon_0 E_{1x} = {{params.P1x}}\,\epsilon_0$; $P_{2z} = ({{params.er2}}-1)\,\epsilon_0 E_{2z} = {{params.P2z}}\,\epsilon_0$; $\rho_{sb} = P_{2z} - P_{1z} = {{params.rho_sb}}\,\epsilon_0\ \mathrm{C/m^2}$, which equals $\epsilon_0(E_{1z}-E_{2z})$: the bound charge alone accounts for the jump in $\epsilon_0 E_z$, since there is no free charge on the interface.
