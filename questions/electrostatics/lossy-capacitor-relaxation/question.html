At $t = 0$ the inner (or lower) conductor holds a charge $Q_0 = {{params.Q0}}\ \mathrm{nC}$ and the other conductor holds $-Q_0$; there is no external circuit. $\mathbf{J} = \sigma\mathbf{E}$ and $\mathbf{D} = \epsilon\mathbf{E}$ have exactly the same field pattern, so the total current $I = \oint\mathbf{J}\cdot d\mathbf{S}$ and the charge $Q = \oint\mathbf{D}\cdot d\mathbf{S}$ are in the ratio $\sigma/\epsilon$ for the same $V$: $G = \dfrac{\sigma}{\epsilon}C$. (Or sum the resistances $dR = dr/(\sigma\,\text{area})$ of thin shells.) With no external current the lossy capacitor's own equivalent circuit ($C$ in parallel with $G$) gives $C\,dV/dt = -GV$, i.e. $dQ/dt = -Q/\tau$ with $\tau = C/G = \epsilon/\sigma$ — independent of the geometry.

(a) {{{params.C_expl}}} $= {{params.C_str}}\ \mathrm{pF}$.

(b) $G = \dfrac{\sigma}{\epsilon}\,C = {{params.G_str}}\ \mathrm{nS}$ (the same formula as $C$ with $\epsilon \to \sigma$).

(c) $\tau = \dfrac{C}{G} = \dfrac{\epsilon}{\sigma} = \dfrac{ {{params.er}}\times 8.854\times10^{-12} }{ {{{params.sigma_tex}}} } = {{params.tau_str}}\ \mu\mathrm{s}$. Every capacitor filled with this medium, whatever its shape, discharges with this time constant.

(d) $Q(t) = Q_0e^{-t/\tau} = {{params.Q0}}\,e^{-{{params.t1}}/{{params.tau_str}}} = {{params.Qt_str}}\ \mathrm{nC}$.

(e) $I(0^+) = GV_0 = G\,Q_0/C = Q_0/\tau = {{params.I0_str}}\ \mu\mathrm{A}$ — equivalently $-dQ/dt$ at $t = 0$.
