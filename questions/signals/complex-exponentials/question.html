Sinusoids and complex exponential sequences. Answer all three parts.

Enter exact values: fractions such as -7/3 are accepted; decimals need 4 significant digits (for example 1.414 for $\sqrt{2}$). Enter angles as a multiple of $\pi$, principal value in $(-\pi, \pi]$: for $\tfrac{3\pi}{4}$ type 3/4.

(a) By Euler's identities the real sinusoid $$x_1[n] = {{params.xa_tex}}$$ can be written as $x_1[n] = c\,e^{j\omega_0 n} + c^*e^{-j\omega_0 n}$ with $\omega_0 = {{params.w0_tex}}$ and a complex constant $c$. Find the magnitude and the principal angle of $c$.

(b) Write $$x_2[n] = {{params.xb_tex}}$$ as a single sinusoid $x_2[n] = A\cos(\omega n + \theta)$ with amplitude $A \ge 0$ and principal phase $\theta$.

(c) Consider the complex exponential sequence $$x_3[n] = {{params.xc_tex}},\qquad -\infty \lt n \lt \infty.$$ Give $\lvert x_3[n]\rvert$ for every integer $n$ as an expression in $n$ (powers with ^, square roots as sqrt(...), fractions rather than decimals; e.g. sqrt(7)*n^2 is valid syntax), and the real and imaginary parts of the sample $x_3[{{params.c_k}}]$.

$\cos\phi = \dfrac{e^{j\phi} + e^{-j\phi}}{2}$ and $\sin\phi = \dfrac{e^{j\phi} - e^{-j\phi}}{2j}$. Sinusoids of the same frequency add like their phasors: $A_1\cos(\omega n + \theta_1) + A_2\cos(\omega n + \theta_2) = \mathrm{Re}\{(A_1e^{j\theta_1} + A_2e^{j\theta_2})\,e^{j\omega n}\}$. For $x_3$ write the base in polar form $r\,e^{j\phi}$: then $(r\,e^{j\phi})^n = r^n e^{j\phi n}$. $\tfrac{1}{j} = -j = e^{-j\pi/2}$, a negative amplitude is a phase shift of $\pi$ ($-1 = e^{j\pi}$), and $\sin\phi = \cos(\phi - \tfrac{\pi}{2})$. $c$ multiplies $e^{+j\omega_0 n}$ (its conjugate goes with $e^{-j\omega_0 n}$). Amplitudes only add when the phases agree. $\lvert e^{j\phi n}\rvert = 1$, so only $\lvert B\rvert$ and $r^n$ set the size. Reduce every angle to $(-\pi, \pi]$.
